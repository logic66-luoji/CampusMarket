## 路径 A：我驱动实操 + gdigrab 真实录屏（推荐先试）

**原理**：ffmpeg 的 `gdigrab` 直接捕获你的真实屏幕/窗口，我在后台通过浏览器
自动化真实操作应用——产出真正的连续录屏（含页面过渡动画与鼠标动作）。

**你需要配合的三个条件**（录制约 7–8 分钟）：
1. 将 ZCode 窗口置前并最大化，应用浏览器面板调整到合适大小（最好近全屏）；
2. 录制期间**不要移动鼠标、不要敲键盘、不要切换窗口**；
3. 关闭/最小化其他窗口（全桌面捕获会录进画面；若告知 ZCode 窗口标题，
   可改为仅捕获该窗口）。

**我负责的流程**：重置演示副本数据库 → 启动应用与演示页 → 启动 gdigrab
捕获 → 按上表真实操作（URL 跳转 + 界面点击，全部已预演验证）→ 停止捕获 →
合成 MP4 + 烧字幕/挂 SRT → 推送仓库。

**开始方式**：回复"开始路径 A"并完成上述三个条件即可；录制中如出错我会
停止并重录对应片段。

## 路径 B：你自行 OBS 录屏（完整执行手册）

### B1. 准备（10 分钟）

1. **环境**：工程根目录执行
   `pip install -r requirements.txt`（或阿里镜像
   `pip install -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com streamlit`），
   然后 `streamlit run app.py` → http://localhost:8501
2. **演示数据**：三种选择
   - 直接用基准库（推荐）：演示中的发布/购买属正常业务数据；
   - 或复制一份 `campus_market.db` 备份，录完还原；
   - **禁止**手工 INSERT 数据或重跑 seed.py。
3. **测试账号**： sellers/买家分别记下侧边栏两个账号（如 `#1 user_0_ndai`
   与 `#2 user_1_fang53`）；视频里切换账号即演示多用户。
4. **终端准备**：另开一个终端窗口 `cd 工程根目录`，备好三条命令
   （performance_test / unittest / sqlite3 查询），字体调大（≥16pt）。
5. **OBS 设置**：
   - 设置 → 视频：基础 1920×1080（或 1600×900），输出 1280×720@30fps；
   - 来源：添加「显示器采集」（全屏）或「窗口采集」（选浏览器窗口）；
   - 设置 → 输出：码率 4000–6000 Kbps，编码 x264，关键帧 2s；
   - 音频：静音（无声+字幕方案）或接麦克风（可选英文旁白，照
     `Video_Script.md` 念）；
   - 快捷键：开始/停止录制设为可盲按的组合键。

### B2. 录制执行（照分镜表 0 节走，约 8 分钟素材）

1. 开始录制前：浏览器 100% 缩放、隐藏书签栏、先静置首页 5 秒再说话/动。
2. 每一幕之间停顿 2–3 秒（给剪辑留切点）；关键操作后停 3 秒
   （如发布成功提示、跳转后的我的购买页）。
3. 侧边栏切换账号前先说/字幕标注"switching account"。
4. 终端两幕：先敲命令再回车，输出停留 ≥5 秒；EXPLAIN 那行输出停留 ≥8 秒。
5. 失败处理：任何一步失败（如重复购买没拦住——不会发生）直接倒回该幕
   重录；剪辑时切掉。
6. 全程英文说明（照 `Video_Script.md`）或纯操作配英文字幕（见 B3）。

### B3. 字幕（无声方案）

两条等价路线：
- **OBS 内嵌**：来源添加「文本 (GDI+)」置于底部，逐段手动换文案（照第 0 节
  的动作列）；优点一步到位，缺点边录边换麻烦；
- **后期挂载（推荐）**：先录干净画面，剪映/PotPlayer 加载
  `presentation/video/CampusMarket-demo.srt`（已按 6:36 版本对齐，自行录制后
  需按你的实际节奏微调时间轴）→ 导出带字幕 MP4。

### B4. 剪辑与导出

- 剪映：导入录屏 → （可选）文字转语音英文旁白 → 挂 SRT → 剪掉失误段 →
  导出 MP4 1080p；
- 或 PotPlayer/在线工具仅合成字幕；
- 检查：时长 5–8 分钟；四个评分点（UI/查询执行/数据流/后端操作）每段
  ≥30 秒画面证据；字幕无错别字。

### B5. 上传与回填

1. 上传 Google Drive / OneDrive / B站，权限设「任何有链接的人可查看」；
2. 把链接发我（或自行替换 `report/Final_Report.md` §9.2 与
   `Section9_Deliverables.md` 的 `[Insert file-sharing URL]`）；
3. 我重导 `CampusMarket-report.pdf` 并推送仓库。
